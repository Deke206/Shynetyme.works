# BTF catalog row-complete import

Source data was rebuilt from the supplied four-page Addressable Pixel Strip quotation and four-page FCOB quotation.

- 131 addressable quotation rows
- 66 FCOB quotation rows
- 34 previously selected ShyneTyme controllers, signal devices, connectors, wiring, rope, kits and pixel systems
- 231 unique public catalog records
- 41 quotation product-group images

The public catalog omits supplier pricing and purchasing links. Exact row IDs flow through catalog selection, simulator recommendations and the customer contact request.
