# ✨ ShyneTyme.Works

### Ideas. Experiments. Websites. LEDs. Electronics. And other things that probably seemed like a good idea at 3:00 in the morning.

Welcome to **ShyneTyme.Works** — the digital workshop of **Dedric “Deke” Alexander**, where a whole lot of ideas are slowly, rapidly, accidentally, intentionally, and occasionally spectacularly coming to fruition in the wonderful wide world of **internetedness**.

ShyneTyme.Works is part portfolio, part laboratory, part playground, part workshop, and part *“Hey... I wonder if I can make this thing do that?”*

Usually, the answer is:

**Probably.**

And then the fun begins.

Some projects begin with a plan.

Some begin with:

> “You know what would be cool...?”

Those are usually the dangerous ones.

## 🎨 The ShyneTyme Idea

The goal is not simply to make things that look good.

The goal is to make things that **do something**.

A website should work.

A lighting system should react.

A simulator should help somebody visualize an idea.

A controller should control something.

A button should preferably cause something interesting to happen.

And if something can light up, animate, communicate, calculate, move, react, connect to Wi-Fi, or otherwise become unnecessarily more interesting than it was when we found it...

**we are probably going to mess with it.**

---

## 🚀 From “What If?” to “Look What I Made”

A lot of ShyneTyme.Works is about taking ideas out of somebody's head and giving them somewhere to exist.

That might mean turning an idea into:

**Idea → Sketch → Experiment → Prototype → Working Project → Better Working Project → “Okay, now what else can we make it do?”**

The website itself follows the same philosophy.

It is not intended to be a frozen brochure.

It is an evolving collection of experiments, demonstrations, tools, projects, mistakes, discoveries, improvements, and things that finally started working after somebody refused to leave them alone.
