# Serial USB Terminal — Android

Use this on the Android phone for CP2102 serial access to ESP32 #2.

Direct Play Store:
https://play.google.com/store/apps/details?id=de.kai_morich.serial_usb_terminal

Purpose:
- Open serial console over USB OTG
- Read boot/debug output
- Send commands when firmware exposes a serial console
- Supports Silicon Labs CP2102
