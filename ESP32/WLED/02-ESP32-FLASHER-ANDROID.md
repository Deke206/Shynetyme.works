# ESP32_Flasher — Android

Use this on the Android phone to flash ESP32 #2 over USB OTG.

Direct Play Store:
https://play.google.com/store/apps/details?id=com.esp_flash.esp_flash_app

Purpose:
- Flash WLED binary from phone storage
- Erase/read/flash ESP32 over USB OTG
- Works with CP2102-based ESP32 boards

For WLED firmware, use the official stable release page:
https://github.com/wled/WLED/releases/tag/v16.0.1
