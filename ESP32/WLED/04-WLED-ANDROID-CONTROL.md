# WLED Android control app

Use this on the Android phone after ESP32 #2 has WLED and is joined to the Wi-Fi AP.

Direct Play Store:
https://play.google.com/store/apps/details?id=ca.cgagnier.wlednativeandroid

Purpose:
- Discover WLED devices on the same Wi-Fi
- Open/control ESP32 #2
- Effects, presets, brightness, segments
- Manual device add by IP if discovery misses it
